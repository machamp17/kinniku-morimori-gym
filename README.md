# 筋肉モリモリジム v2 — Phase 0 / Phase 1 見本

公開版: https://machamp17.github.io/kinniku-morimori-gym/

## ベータ版（この端末に保存）

- 記録（トレーニング・からだ）・見た目・設定は、使っている端末のブラウザ内（localStorage）だけに保存します。ログインやクラウド保存はありません（Phase 2 で対応）
- 機種変更・ブラウザのデータ削除・別ブラウザでは記録が見えません。設定 > 記録のデータ から JSON で書き出し／読み込みできます
- EXP は保存した記録から仕様書 5.4 どおりに計算（完了セット1つ5EXP、記録日・部位ごとに上限30、記録日ごとに継続+10）
- 共有ジムのほかの人は見本（架空）です。自分は公開ONで直近24時間に記録した時だけ表示
- ホーム画面に追加でき、オフラインでも開けます（sw.js）

仕様書 v2.0（`../kinniku_morimori_gym_spec.md`）に基づく **Phase 1 の見た目確認用デモ** です。
認証・クラウド保存・課金は未実装（Phase 2〜4）。アプリ完成版ではありません。

## 起動

```bash
python -m http.server 5191   # このフォルダで実行
```

- アプリ見本: http://localhost:5191/ （スマホ幅で確認。PC では中央に 480px 幅で表示）
- キャラ見本シート: http://localhost:5191/art-sheet.html （`?zoom=1` で2倍表示）
- 見本の切替: アプリの 設定 > 見本の操作（成長段階・参加者数 0/12/20/23・保存失敗の再現）
- 画像の再生成: `node tools/render-sheet.mjs <stages|shoulders|faces|hair|haircolor|skins|tops|bottoms|maxwear|gym> <倍率> <出力.png> [列数]`

見本は `localStorage` の `kmg2.demo.*` だけを使います（旧版の `kmg.*` には触れません）。

- 体: 少し足を開き腕を外へ出した立ち姿、握りこぶし、腕・脚を一続きの円柱として陰影、服のすそ・脇のしわ、上衣→下衣・袖→腕・あご→首の落ち影、光の側を明るくする輪郭（セレクティブアウトライン）、耳を小さく
- 表情は変更なし（承認済みのため）
- ジム: 格子状の並びをやめ、バラバラな配置に（`tools/gym-layout.mjs` で作成。どの2人もタップ領域が重ならない条件付き）。人数が少ない時も散らばる順で埋める

## 第3巡の修正（依頼者の指摘を受けて）

- 上半身の初期ウェアをタンクトップに統一（Tシャツは着せ替えで選択可）。素肌の肩が腕と自然につながるよう陰影を統一
- 表情を3種→11種（にっこり・満面・ほっこり・ニカッ・ウインク・キラキラ・ドヤ・照れ・びっくり・集中・ファイト）。着せ替えに「表情」タブを追加
- 髪型を15種→23種（ツンツン・七三分け・ウルフ・アフロ・ショートボブ・サイドテール・おさげ・ハーフアップを追加）
- 肩は5段階→Lv1〜13の13段階で1レベルごとに広がる（上限は詳細2.2倍・ジム1.6倍のまま）。他の部位もレベルに応じて連続的に変化
- ジムの吹き出しを同時3人に（吹き出し同士が重ならない位置の人を組み合わせる）。仕様書9.4の「同時最大2つ」からの変更
- ロゴをドット書体 DotGothic16（Google Fonts・SIL Open Font License、商用可）で描いたドット絵に。2値化・太字化・グラデーション・縁取り・影・ダンベル。フォントが読めない環境では通常の文字で表示

## 既知の問題・未解決

- **アート未承認**。コードで描いたスプライトのため、手描きのドット絵作家による素材と比べると服のしわや髪の毛束の表現は単純です。承認されなければ、外部制作の要否を含めて相談が必要です
- 肩幅最大（詳細）では肩の球があごの横まで来ます（顔には重なりません）。ギャグとして許容か確認してください
- 動きは 2 フレームの上下（idle）のみ。達成時の4フレーム動作は未制作
- ジム用 96px を 48 CSS px で表示するため、画素比3の端末では 1.5 倍の端数拡大になります
- 200%文字拡大・キーボード表示時の実機確認、初見利用者テストは未実施
- `claude_code_prompt_kinniku_morimori_gym.md` v2.0 のファイルが見当たりません（旧版はごみ箱内）
